This disk image contains a file. Find the flag. (archivo 1000.tar anidado)
## Solución
Descargué 1000.tar. Resultó ser un archivo .tar anidado 1000 veces: cada .tar contenía dentro una carpeta con el siguiente .tar (999.tar, 998.tar, ...) más un filler.txt de relleno. Hice un script que iba extrayendo cada nivel automáticamente hasta llegar al fondo, donde en lugar de otro .tar había un flag.png. Al abrir esa imagen apareció la flag:

academy{l0t5_0f_TAR5}
## Notas Adicionales
- Se resuelve con un bucle que extrae tar tras tar (1000 niveles); cada nivel trae un filler.txt como ruido.
